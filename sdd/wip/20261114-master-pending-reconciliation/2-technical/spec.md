# Spec técnico

Cambio exclusivamente documental sobre `sdd/STATUS.md`, `sdd/RELEASE.md` y los
paquetes SDD de reconciliación/paridad. La autoridad son `master`, los PR y runs
alojados observados. La evidencia conserva identidad de SHA y no se hereda para
homologaciones externas.

No se modifican TypeScript, Kotlin, SQL, workflows, configuración ni secretos.
