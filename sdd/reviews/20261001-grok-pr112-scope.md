## Write path

`OfferStatus` and `DiscountType` are Kotlin `sealed class` types. Each known wire is a `data object`. Each type has one `fromWire` translator and an `Unknown` case whose `wire` is `unknown`.

`JdbcOfferService.save` calls `OfferStatus.fromWire` and rejects anything with `writableOnCreate == false` (`PAUSED`, `ENDED`, `Unknown`) as `OFFER_STATUS_INVALID`. It calls `DiscountType.fromWire` and rejects `Unknown` as `OFFER_DISCOUNT_INVALID`. Inserts persist `status.wire` and `discountType.wire`. An `Active` insert still sets `approved_by` and `approved_at`; a draft insert still writes those columns as NULL.

`JdbcOfferService.changeStatus` rejects only `Unknown`. `Draft`, `Active`, `Paused`, and `Ended` remain writable on that route. The approval CASE compares the bound status wire to `OfferStatus.Active.wire` (eight placeholders, eight arguments). List and load still return the stored strings; this cut does not retarget the read model.

`OfferWriteTypesTest` asserts draft/active (including a trimmed ` ACTIVE `), create flags for paused/ended/unknown, unknown status wires (`SCHEDULED`, blank, null) without echoing them, and percent/fixed versus `percent`, `BOGO`, and null.

`fromWire` trims, matching `OrderStatus` and the other commerce translators already on this line. The value stored is the canonical wire, not the padded input.
