## Required change

«Este home no tiene bloques para el banner.» is true only while the latest successful public read returned an empty `blocks` array. `4a1760c` also leaves that sentence up after Publicar has created the first banner block.

On a successful `loadHome`, `homeBlocks` is `published.blocks` from `GetHomeUseCase` (`GET /content/home` → `mapHome`). The live `home()` always serializes `blocks`. An empty array means no active home sections. The storefront carousel is that same list (`slice(0, 5)`), so length 0 is a real empty banner. The template shows the sentence only inside `@if (!state.loading && !state.errorMessage && state.homeBlocks)` when `length === 0`. That part matches the public read.

`saveHome` then does `INSERT ... VALUES ('hero', ..., active=true)` (update on conflict does not clear `active`). A home with no active sections gains a hero block on the first successful publish. `persistHome` still sends `{ title, body }`. The PUT response is `HomeDraft` (title + body, no `blocks`). `mapHomeDraft` leaves `blocks` undefined, and this branch keeps the previous list:

```191:196:frontend/src/app/features/admin/user.store.ts
            next: (home) =>
              this.patchState({
                home: { title: home.title, body: home.body },
                ...(home.blocks === undefined ? {} : { homeBlocks: home.blocks }),
                loading: false,
              }),
```

`loading` returns to false and `errorMessage` stays empty, so the pre-save `[]` paints the sentence again. The lede says the section is what the public home is rotating now. After that insert, the public home has a hero block. The sentence is false until the next `loadHome`.

That is the empty-home path: `adminHomeDraft()` already supplies a non-blank default title, so Publicar is enabled while the sentence is showing.

Do not paint the sentence from the pre-save array after a successful publish. Re-read the existing public `GET /content/home` after save, or clear `homeBlocks` to `null` until that read returns. Keep the sentence hidden while that read is loading or in error. Do not assign `homeBlocks` from the console draft: a console `blocks: []` would again claim the banner is empty without a public read. Save stays title + body. No new endpoint, no Kotlin, no invented slides.
