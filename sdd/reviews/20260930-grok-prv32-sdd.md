## Residuals (non-blocking)

**P2 — `join` booleans are not asserted.** Overlapping adjusts, the four-way inventory race, and pause use `join(timeout)` and then assert quantities, version, errors, or `PAUSED`/`WITHHELD`. A thread that never finishes fails those asserts. The boolean itself is unused.

**P2 — admin wait is a 400ms liveness check, plus the separate `lock_timeout` probe.** `awaitBlockedOnSnapshot` does not raise `lock_timeout` inside `replaceKill` / `removeKill` / `changeState`. `createKill` runs after the first holder commits so replace has an id. The timed-out `FOR UPDATE` is on the same `capability_actions` row Tx-C locks before those branches.

**P2 — failed delivery is still the reserve unit.** Consume and release are raced on the success path in this class. They are not a second injected delivery failure. AC-DSP-04's rollback of balance, ledger, reservations, payment/order/attempt, projection, and outbox is what the multi-SKU reserve test shows.

**P2 — `switches` is asserted as an array, not as a populated kill.** This photo is taken while `MARKETPLACE_ML` is `DISABLED` and this method has not created a switch. A missing `switches` node would fail `isArray`.

**P2 — coalescence predicate is version equality.** BR-DSP-04 forbids a dispatcher claim query here. The test does not pretend to check mapping fingerprint, ACTIVE flags, or account eligibility.
