## Implementation review

### HTTP surface and auth

Six routes under `/api/v1/internal/admin/blackstore-companion`: POST `pair`, `rotate`, `activate`, `suspend`, `revoke`; GET `commands/{correlationId}`. Mutations require `X-CSRF-Token`, `@Valid` body with `correlationId` UUID, `reason`, and operation fields. `RequestAuth.requireSameOrigin` + `auth.admin(http)` on every handler. GET status requires admin + same origin (no CSRF — aligned with capability status pattern).

`CompanionAdminCommandService` performs runtime Tx-S (CSRF verify + rotate via `TransactionTemplate`) then invokes companion-admin pool SQL — mirrors `CapabilityAdminCommandService` CSRF split without reusing capability intent table (companion durable correlation lives in V9 `companion_admin_prepare_command`).

### Secret provider and bearer-once

`CompanionSecretProvider.prepare` now returns `PreparedCompanionSecret(secretRef, fingerprint)`; `InMemoryCompanionSecretProvider` is idempotent per `requestId` and never exposes ref in HTTP views. `JdbcCompanionAdminCommands` runs Tx-P (`prepare` → `secrets.prepare` → `attach` → `pair`/`rotate` SQL); `finishSecretCommand` resolves bearer hex once, `statusWithoutBearer` / `readStatus` strip bearer and refs on replay/status. Aborted SQL paths call `secrets.discard`.

### Closed types and envelope

- `HttpCode` sealed hierarchy with `fromWire`/`Unknown` in `com.storecore.shared.http`.
- `CompanionAdminOperation`, `CompanionLifecycleStatus`, `CompanionScope` closed at domain edge; controller maps wire strings through `fromWire`.
- `BaseResponse` companion factories preserve six-field contract; success responses set `data`, errors set `data=null` with `errorCode`/`retryable`/`traceId`.

### Pool and fail-closed

`CompanionAdminDataSourceConfig` wires `storecore.companion-admin.datasource.*`; bean absent when property missing. `JdbcCompanionAdminCommands.admin()` throws `CompanionAdminPoolMissing` → advice 503 retryable. Tests provision dedicated login (`CompanionAdminTestSupport`) member of `storecore_companion_admin`.

### SDD / residual alignment

- `Posc002fAcceptanceMatrixTest.eightContractRoutesStayPinnedAndCompanionAdminControllerExists` flips 002F “no CompanionAdminController” residual.
- `sdd/STATUS.md` and slice doc record residual on branch; explicitly do not close POSC-002 or unlock POSC-003.
