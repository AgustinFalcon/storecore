## Implementation review

### Domain (closed types)

- **`CatalogVersion` / `PriceVersion`:** Sealed hierarchy with private constructors, single `fromWire` translator, `Unknown` for invalid wire — aligns with workspace closed-domain rule. Labels `CURRENT`/`UNKNOWN`, `QUOTED`/`UNKNOWN` for UI/tests without string compares in production paths.  
- **`OfferWindow`:** Canonical half-open predicate centralized; reused in SQL fragment and pure `contains()` for unit tests.  
- **`VersionDigest`:** Length-prefixed UTF-8 tuple SHA-256 → base64url (43 chars), matching proposal digest shape for `c1_`/`p1_`.

### `JdbcPriceQuoteAdapter`

- **`clock()`:** `clock_timestamp()` — DB-as-of, not JVM clock.  
- **`shareRevision()`:** Delegates to 003A `blackstore_catalog_revision_share()`.  
- **`catalogVersion(asOf)`:** Tuple `c1`, revision counter, installation currency, ordered ACTIVE offer IDs whose window contains `asOf`; digest → `CatalogVersion.current`.  
- **`quoteByVariantIds` / `quoteBySkus`:** Shared `load()` with lateral offer selector (half-open window, `priority DESC, id ASC`), PERCENT/FIXED discount with `HALF_UP` scale-2, cents encoding in `priceVersion` tuple.  
- **Conditional wiring:** `@ConditionalOnProperty(storecore.identity.enabled=true, matchIfMissing=true)` consistent with replaced adapters.
