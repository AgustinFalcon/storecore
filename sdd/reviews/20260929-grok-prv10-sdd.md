## What the slice gets right (evidence-backed)

- **Closed domain types at wire edge:** `CompanionScope`, `CompanionLifecycleStatus`, `CompanionServiceRole` with `fromWire` → `Unknown`; route matrix returns typed scopes (`CompanionScopeTest.kt`).
- **Fingerprint selects, bytes authenticate:** lookup by SHA-256 fingerprint, then constant-time compare with provider bytes; legacy `auth_ready=FALSE` stays `Invalid` (`DefaultCompanionCredentialVerifier.kt:24-52`; `CompanionCredentialVerifierTest.kt:21-44`).
- **Immutable principal:** internal constructor; scopes/role frozen from credential record (`VerifiedCompanionPrincipal.kt`).
- **Buffer hygiene:** bearer and resolved secret bytes zeroed after compare (`DefaultCompanionCredentialVerifier.kt:47-49`).
- **Scope matrix covers seven business routes + reconcile** (`CompanionRouteScopeMatrix.kt:8-17`); OpenAPI exempt (`CompanionAuthInterceptor.kt:26`).
- **Header binding fail-closed:** header-only (no bearer) → 401 (`Posc002dCompanionAuthHttpTest.kt:41-43`); missing/malformed instance id → 400/`VALIDATION`; mismatch → 403/`FORBIDDEN` (`CompanionAuthInterceptor.kt:33-40`).
- **Malformed/short bearer → 401:** non-hex and sub-256-bit tokens rejected before lookup (`Posc002dCompanionAuthHttpTest.kt:45-48`).
- **Missing scope → 403:** `catalog:read`-only principal denied on `GET /stock/variants/{id}` (`Posc002dCompanionAuthHttpTest.kt:60-62`).
- **Revoked credential → 401:** DB `status='REVOKED'` after fingerprint match fails verifier (`Posc002dCompanionAuthHttpTest.kt:64-67`).
- **Companion DISABLED after auth → 403** before capability (`CompanionAuthInterceptor.kt:41`; HTTP test line 56-58).
- **`includeCost=true` always denied** at interceptor regardless of scopes; regression contract test preserved (`BlackStoreHttpContractTest.kt:109-115`).
- **Provider outage → 500 retryable**, not false 401 (`DefaultCompanionCredentialVerifier.kt:38-40`; HTTP test line 76-78).
- **BaseResponse envelope:** `code`, `data=null`, `errorCode`, `retryable`, `traceId` asserted in HTTP test (`Posc002dCompanionAuthHttpTest.kt:106-113`).
- **No YAML/Flyway drift:** OpenAPI resource untouched; V9 schema consumed read-only via `JdbcCompanionCredentialLookup`.
- **Existing suites adapted:** fail-closed and contract tests seed bearer so interceptor auth precedes capability checks (`BlackStoreFailClosedHttpTest.kt`, `BlackStoreHttpContractTest.kt`).
