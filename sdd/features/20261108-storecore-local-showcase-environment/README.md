# StoreCore local showcase environment

API-driven, disposable local showcase loading is implemented and integrated. It uses authenticated StoreCore contracts, keeps external providers disabled, creates only a pending local checkout and supports deterministic replay.

PR #230 passed its exact-head CI but retrospective reviews found two P2 defects. They were fixed by the subsequent PSD integration and CI hardening commits, so this feature is archived as `completed_via_successor_hardening`, not as an approval of the historical PR head.

No live provider, homologation, release or deployment is claimed.
