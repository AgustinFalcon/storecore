# Especificación funcional

## Reglas

- Una tarea de entrega se marca completa sólo con PR fusionado y ambos gates
  alojados exitosos: exact-head y post-merge.
- Los comentarios y estados de issues deben conservar residuales honestos.
- No se cierran multimedia, Correo Argentino, email productivo, Mercado Pago
  live, ARCA, Store Coins ni dispatchers futuros.
- Esta entrega no modifica comportamiento de usuario ni contratos de runtime.

## Aceptación

- Se reconcilian únicamente los WIP asociados a PR #274, #275, #276, #282,
  #285 y #308.
- Cada cierre cita merge y runs verificables.
- El árbol queda sin tareas de entrega obsoletas para esos seis cortes.
- El estado canónico refleja el master vigente y no confunde un subcorte de
  media inactivo con el cierre del pipeline o del issue #7.
